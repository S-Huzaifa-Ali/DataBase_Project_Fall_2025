## 1. Introduction

The rapid growth of online shopping has made e-commerce platforms an essential part of modern business. This project proposes the development of a database-driven e-commerce website using the Django framework. The system will provide customers with a seamless shopping experience while offering efficient tools for product management, customer handling, inventory control, billing, and order processing.

## 2. System Functions

- **Inventory Control** — Track product stock levels and update them automatically after each order.  
- **Billing** — Calculate order totals, apply discounts (if any), and generate bills for customers.  
- **Ordering** — Allow customers to place, view, and track their orders.  
- **Customer Management** — Support user registration, login, profile management, and multiple addresses.  
- **Cart Handling** — Enable users to add/remove products to/from the cart with automatic price calculation.  

## 3. Front-End and Back-End Technologies

- **Backend**: Django Framework (Python)  
- **Database**: db.sqlite3 with full CRUD operations  
- **Frontend**: Django Templates, HTML, CSS, and Bootstrap for responsive design  

## 4. Database Design

The project will follow proper database design principles, including:  
- Creation of an Entity-Relationship (ER) Diagram  
- Normalization up to at least 3NF  
- Implementation of relationships between entities (e.g., User, Product, Order, Cart, etc.)  

## 5. Conclusion

This proposal presents a database-focused e-commerce website project that fulfills the requirements of inventory control, billing, ordering, and customer management. The system will use Django for backend logic and SQL for data management, ensuring normalization and ER design principles are applied. This structure provides a solid foundation for the implementation phase of the project.
